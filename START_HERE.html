Customization Guide

Change Company Information

  1. Open any HTML file in a text editor
  2. Find and replace:
    • NESTYM → Your company name
    • hello@nestym.co.ke → Your email
    • +254 XXX XXX XXX → Your phone
    • Nairobi, Kenya → Your location
  3. Save the files

Modify Colors

  1. Open css/style.css
  2. Find the :root {} section at the top
  3. Edit these main colors:
    • --accent-cyan: #00d9ff; ← Neon cyan
    • --accent-blue: #0066ff; ← Electric blue
    • --primary-dark: #0a0e27; ← Main background
  4. Refresh your browser to see changes

Add New Content

  1. Copy an existing card/section (service-card, project-card, etc.)
  2. Paste into the appropriate section
  3. Update the text content and emoji icon
  4. Styling automatically applies

Troubleshooting

Pages not loading?

Make sure all files are in the correct folders. Check that relative paths are correct.

Styling looks wrong?

Verify css/style.css is in the css/ folder. Hard refresh your browser (Ctrl+F5).

Links not working?

Check that file paths match the folder structure. Use relative paths (e.g., ../index.html from pages folder).
