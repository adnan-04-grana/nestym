# NESTYM - Modern Technology Company Website

## 🚀 Project Overview

NESTYM is a modern, futuristic, and professional technology company website built entirely with **HTML and CSS**. It represents a Kenyan-based technology company specializing in software development, system development, web & mobile applications, cloud solutions, and digital services.

```
├── css/

```

## 🛠️ How to Use

### Opening the Website
1. Open `index.html` in your web browser
2. Navigate using the menu bar
3. All pages are fully functional and interconnected

### Local Development
- No build process needed
- No dependencies to install
- Just open HTML files directly in browser
- Easy to edit CSS and HTML

### Customization

**Updating Colors:**
Edit CSS variables in `css/style.css`:
```css
:root {
    --accent-cyan: #00d9ff;
    --accent-blue: #0066ff;
    /* ... other colors ... */
}
```

**Adding New Content:**
- Copy existing card/section HTML structure
- Paste into appropriate page
- Update text content
- Styling automatically applies

**Modifying Animations:**
- Look for `@keyframes` in CSS
- Adjust animation durations and delays
- Change transform and opacity values

## 💡 Customization Tips

### Adding New Services
Copy this template in appropriate section:
```html
<div class="service-card">
    <div class="service-icon">🎯</div>
    <h3>Service Name</h3>
    <p>Service description and details...</p>
</div>
```

### Changing Company Information
Find and update these sections:
- Company name: Search for "NESTYM"
- Email: Search for "hello@nestym.co.ke"
- Phone: Search for "+254"
- Location: Search for "Nairobi, Kenya"

### Modifying Brand Colors
Update in `css/style.css`:
```css
--primary-dark: #0a0e27;      /* Main background */
--accent-cyan: #00d9ff;       /* Neon cyan */
--accent-blue: #0066ff;       /* Electric blue */
```
